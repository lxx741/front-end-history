# 前端发展史时间轴

一个交互式的网站，展示从1990年到2025年前端技术的发展历程。使用时间轴的形式，生动呈现前端技术的演进、重要事件和里程碑。

## ✨ 特色功能

### 🎯 核心展示
- **全面覆盖**：包含技术标准、框架工具、浏览器、组织机构等多个维度
- **时间跨度**：1990-2025年，35年前端发展完整历程
- **事件分类**：技术标准、框架工具、浏览器、组织机构、开发工具、重要里程碑
- **重要性分级**：关键、重要、一般、次要四个等级

### 🎨 视觉设计
- **创意活泼风格**：丰富的动画效果和视觉元素
- **年代色彩区分**：不同年代使用不同的配色方案
- **代码雨背景**：程序员熟悉的代码元素作为装饰
- **几何图形动画**：浮动旋转的几何形状增添活力
- **渐变时间轴**：彩色渐变的垂直时间线

### 🔧 交互功能
- **智能搜索**：实时搜索事件内容，支持快捷键 Ctrl+F
- **分类筛选**：按类别快速筛选显示的事件
- **快速导航**：侧边栏年份导航，一键跳转到指定年份
- **键盘导航**：支持数字键快速切换分类
- **导出功能**：导出时间线数据为JSON格式
- **响应式设计**：完美适配桌面端和移动端

### 🚀 技术特性
- **性能优化**：使用Astro静态站点生成器，加载速度快
- **现代CSS**：基于Tailwind CSS，样式高度可定制
- **无障碍**：支持键盘导航和屏幕阅读器
- **SEO友好**：语义化HTML结构，良好的搜索引擎优化

## 🛠️ 技术栈

- **框架**：[Astro](https://astro.build/) - 静态站点生成器
- **样式**：[Tailwind CSS](https://tailwindcss.com/) - 原子化CSS框架
- **语言**：TypeScript - 类型安全的JavaScript
- **交互**：原生JavaScript - 无依赖的交互功能
- **构建**：Vite - 快速的构建工具

## 🚀 快速开始

### 环境要求
- Node.js 18.0.0 或更高版本
- npm 或 yarn 包管理器

### 安装步骤

1. **克隆项目**
   ```bash
   git clone <repository-url>
   cd front-end-history
   ```

2. **安装依赖**
   ```bash
   npm install
   ```

3. **启动开发服务器**
   ```bash
   npm run dev
   ```

4. **打开浏览器**
   访问 http://localhost:4321 查看网站

### 构建部署

```bash
# 构建生产版本
npm run build

# 预览构建结果
npm run preview
```

## 📖 使用指南

### 浏览时间线
- 滚动页面浏览时间线，事件会自动淡入显示
- 点击侧边栏的年份可以快速跳转到指定年份

### 搜索功能
- 在搜索框中输入关键词，实时过滤显示的事件
- 支持事件标题和描述的搜索
- 按下 Ctrl+F 快速聚焦搜索框
- 按下 ESC 清除搜索条件

### 分类筛选
- 点击顶部的分类按钮，按类别筛选事件
- 使用数字键 1-7 快速切换到对应分类
- 分类包括：全部、技术标准、框架工具、浏览器、组织机构、开发工具、重要里程碑

### 导出数据
- 点击"导出"按钮可以将时间线数据导出为JSON文件
- 导出的数据包含年份、标题、描述、分类和重要性信息

### 键盘快捷键
- `Ctrl+F`：聚焦搜索框
- `ESC`：清除搜索条件
- `1-7`：快速切换分类筛选
- `↑↓`：滚动页面

## 🎨 自定义配置

### 修改样式主题
编辑 `tailwind.config.mjs` 文件中的颜色配置：

```javascript
theme: {
  extend: {
    colors: {
      era: {
        '90s': '#475569',    // 90年代配色
        '00s': '#10b981',    // 00年代配色
        '10s': '#8b5cf6',    // 10年代配色
        '20s': '#ec4899'     // 20年代配色
      }
    }
  }
}
```

### 添加新事件
编辑 `src/data/timeline.json` 文件，按以下格式添加新事件：

```json
{
  "year": 2025,
  "events": [
    {
      "id": "2025-001",
      "title": "事件标题",
      "description": "事件描述",
      "category": "technology",
      "importance": "high",
      "icon": "🚀"
    }
  ]
}
```

### 修改分类配置
编辑 `src/data/config.ts` 文件中的分类定义：

```typescript
export const CATEGORIES = {
  technology: {
    name: 'technology',
    label: '技术标准',
    color: '#3B82F6',
    bgColor: '#DBEAFE'
  }
  // ... 其他分类
};
```
